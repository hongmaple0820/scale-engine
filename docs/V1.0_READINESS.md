# v1.0 收敛与就绪评估

Status: P4-F（评估 + 收敛口径）
Scope: 定义 v1.0 的语义、就绪清单与自评体系换届

## v1.0 语义（学 spec-kit 1.0 的坦诚）

spec-kit 在 1.0 时说「1.0 只是个数字，价值从稳定转向可适应」。SCALE 采用同一坦诚：
**v1.0 = 能力承诺（capability commitment），不是稳定性承诺**。即「承诺以下能力已实现并可验证」，
而非「API 永不变更」。
